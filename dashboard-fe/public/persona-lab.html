Step 1

실험 조건

사이트, 실험, cohort 필터를 정하면 아래 해석과 simulation 결과가 같은 기준으로 갱신됩니다.
화면 편집기 열기
실험실을 초기화하는 중입니다.
Step 2

선택 agent 전이확률 분석

현재 cohort 필터 기준으로 A안 baseline 전이확률과 B안 변경 후 전이확률을 비교합니다.
실험과 cohort 필터를 선택한 뒤 분석하세요.
아직 전이확률 분석 결과가 없습니다.
Step 3

가상 agent로 돌려보기

현재 실험과 cohort 필터를 기준으로 Nemotron 고정 10k 코호트의 일치 집합만 실행합니다.
실험을 선택한 뒤 cohort 필터에 맞는 agent 집합으로 실행하세요.
가상 agent 실행 결과가 아직 없습니다. 결과는 synthetic persona simulation이며 실제 사용자 행동의 증명은 아닙니다.
